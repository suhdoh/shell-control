# Third-party components

Shell Control invokes these tools; their binaries are obtained from their respective distributions:

- [Windows Terminal](https://github.com/microsoft/terminal)
- [PowerShell](https://github.com/PowerShell/PowerShell)
- [Fastfetch](https://github.com/fastfetch-cli/fastfetch)
- [eza](https://github.com/eza-community/eza)
- [Gum](https://github.com/charmbracelet/gum)
- [Oh My Posh](https://github.com/JanDeDobbeleer/oh-my-posh)
- [Nerd Fonts](https://github.com/ryanoasis/nerd-fonts), pinned release v3.5.1

Each tool retains its upstream license. Each installed font includes the license supplied in its upstream archive. Recommended and full packs use terminal-compatible Nerd Font variants. Proprietary Apple font files are not included or downloaded.

## Theme color values

- Rosé Pine: [rose-pine/windows-terminal](https://github.com/rose-pine/windows-terminal), MIT. Notice included in `assets/licenses/rose-pine.txt`.
- Catppuccin: [catppuccin/windows-terminal](https://github.com/catppuccin/windows-terminal), MIT. Notice included in `assets/licenses/catppuccin.txt`.
- Gruvbox: [morhetz/gruvbox](https://github.com/morhetz/gruvbox), by Pavel Pertsev; MIT as declared in its `package.json`. Shell Control maps the upstream palette into six Windows Terminal variants. No Vim implementation is copied.
- SynthWave '84: [robb0wen/synthwave-vscode](https://github.com/robb0wen/synthwave-vscode), MIT. Notice included in `assets/licenses/synthwave84.txt`.
- Osaka Jade: color palette from [Omarchy](https://github.com/basecamp/omarchy). MIT notice included in `assets/licenses/osaka-jade.txt`.
- Amber 340, Matrix and Dark Crimson: Shell Control palette variants.

Theme names remain associated with their original projects. The Shell Control MIT license does not replace upstream notices.
